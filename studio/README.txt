Распакуйте архив и откройте CueHunters.rbxlx через File → Open from File в Roblox Studio. Нажмите Play (F5). Для локального запуска публикация не требуется.

Audio содержит десять WAV. Preview.mp3 позволяет прослушать подборку. Пока в SoundService → ClubAudio не указаны Roblox SoundId, игра использует звуки из своей резервной библиотеки.

God Mode привязан к Roblox UserId 1221663569. Запустите Play (F5) под этим аккаунтом и откройте Settings → God Mode.

Режим камеры (только для аккаунта владельца): Settings → Camera mode или Shift+C.
1 — свободный полёт: WASD, Q/E вниз/вверх, правая кнопка мыши — обзор, Shift — быстро, Alt — точно, колесо — скорость, Z/X — зум, R/T — наклон, Backspace — сброс.
2 — облёт вокруг персонажа (колесо — дистанция, W/S — высота). 3 — автоматические красивые кадры.
F — фильтр (Film, Golden hour, Noir, Dream, Off), H — скрыть панель (на телефоне: тап в правый верхний угол вернёт её), Shift+C — выход.
На телефоне в режиме камеры: джойстик слева — полёт (в облёте — высота и поворот), свайп по экрану — обзор, два пальца — зум, кнопки справа — вверх/вниз, скорость, зум, наклон. Геймпад: левый стик — полёт, правый — обзор, L2/R2 — вниз/вверх.
